## 弹性公网IP按什么收费？先认清三个计费项

不管哪家云厂商，EIP的账单都由三个计费项组合而来，差别只在每种计费模式勾选了其中几项。

**带宽费**：按你购买的带宽大小收费，不限流量。阿里云的包年包月和按量按固定带宽两种模式都收这项；天翼云写得更直白，“无论是否绑定，均按带宽占用收费”。

**流量费**：按实际流量收费，但只看出方向。阿里云按“从数据中心指向互联网”的流量累计收取，入方向不参与计费；天翼云只收出云方向；京东云只统计“出京东云方向”；华为云则只对出云带宽收费。

**IP保有费（配置费）**：可以理解为公网IPv4地址本身的“占位费”，只挂在按量付费模式上，绑定状态决定收不收。

> 容易被忽略的一点：入云流量——用户往你的服务器上传文件、你在服务器里下载资源——在主流云厂商这里都不收费。账单超预期时，先查出方向流量和保有费，不用在入方向上浪费时间。

## 最容易超预算的一项：IP保有费（配置费）

保有费的逻辑很简单：只要这个公网IPv4地址被你占着，哪怕一个月没有任何流量经过，也按小时收钱。

阿里云两种按量模式都含EIP配置费，官方文档里单独列有“不收取EIP配置费的情况”，开通前建议对照自己的绑定方式确认一遍。

天翼云的规则写得最细，2025年9月15日起执行：

- 不收：按量EIP直接绑定云主机或物理机主网卡的主私网IP；
- 收：空绑、绑定虚拟IP、绑定负载均衡、绑定NAT网关、绑定主机辅助网卡，都在收费范围；
- 价格从0.1元/个/小时下调到**0.02元/个/小时**，按小时收，不足一小时按一小时算；
- 还有一条容易被共享带宽的优惠掩盖：EIP加入共享带宽或买了共享流量包，只要没绑定实例，保有费照收。

京东云按用量计费的EIP每小时收一次保有费，官方帮助文档的计费示例是：一天出流量1GB，加一天保有费，合计1.28元（保有费0.48元/天，流量0.8元/GB），示例价格以实际账单结算为准。

按0.02元/小时的量级估算，一个空绑EIP挂满一个月是**14块多**。一台服务器配一个EIP、常年绑在主网卡上，这点钱可以忽略；手里攒了几个“以后可能用”的EIP，就该清一清了。

## 弹性公网IP收费常见问题

### 弹性公网IP不用也扣钱吗？

分模式。包年包月扣的是整个周期的带宽费，闲着也一样；按量模式会叠加保有费，天翼云空绑EIP按0.02元/小时收，阿里云按量模式含配置费。不打算用的EIP，释放是最直接的止损方式。

### 入方向流量收费吗？

不收。阿里云明确入方向流量不参与计费，天翼云、京东云、华为云同样只收出方向。

### 包年包月的EIP能提前退吗？

京东云在计费规则里写明：包年包月资源到期前不支持删除操作，到期后立即停止服务，资源和数据保留7天。其他厂商的退订规则各有不同，下单前翻一遍条款。

### 绑定负载均衡或NAT网关后，保有费还收吗？

天翼云的答案是收——免收条件只限绑定云主机或物理机主网卡的主私网IP，绑SLB、NAT网关、虚拟IP、辅助网卡都会触发保有费，加入共享带宽也不豁免。阿里云的免收情形以官方文档“不收取EIP配置费的情况”为准。
